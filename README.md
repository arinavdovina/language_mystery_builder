# Language Mystery Builder

Многофайловый статический прототип конструктора детективных языковых уроков.

## Файлы
- `index.html` — интерфейс.
- `style.css` — дизайн и адаптивность.
- `data.js` — 30 детективных сюжетов, 12 типов материалов дела и 120 форматов заданий.
- `app.js` — выбор сюжета, фильтры, авто-подбор Workbook, сохранение черновика и генерация двух промптов.

## Запуск
Откройте `index.html` в браузере. Сервер не требуется.

## Что уже работает
- 3 режима настройки.
- Профиль ученика и урока.
- 30 дел с поиском и фильтрацией.
- Case file из 1–5 источников.
- 120 заданий по 8 категориям.
- Рекомендации под выбранное дело и навыки.
- Auto Build на 4–10 заданий в зависимости от длительности.
- Свои задания, число пунктов и сложность.
- Evidence Board, Final Verdict, answer key.
- Отдельный prompt для script/evidence и prompt для Workbook.
- Teacher Brief.
- Копирование и локальное сохранение черновика.
